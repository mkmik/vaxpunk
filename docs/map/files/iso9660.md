VMS reads two CD-ROM structures besides Files-11: ISO 9660, which it
treats internally as ODS-3, and its predecessor High Sierra, ODS-4.
OpenVMS VAX V6.0 and AXP V1.5 brought them into the base system; earlier
VAX releases needed the F11CD kit. A disc that carries both ODS-2 and
ISO 9660 mounts as ODS-2 unless `MOUNT/MEDIA_FORMAT=CDROM` asks for ISO
9660. Files have no RMS attributes there, so `/UNDEFINED_FAT` says what to
take them as, for example `STREAM:2048`. The Rock Ridge extensions are
not supported. VMS's own distribution CDs are ODS-2.

vaxpunk mounts Files-11 only. Nothing plans CD-ROMs; QEMU could attach
an ISO image as a disk, which is how files would come over from the host
this way.
